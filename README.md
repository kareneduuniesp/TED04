# Little Memories Photobooth

Uma cabine de fotos que roda direto no navegador. Você liga a câmera, escolhe filtro, moldura e adesivo, tira **4 fotos em sequência** e baixa uma **tira de fotos** pronta em PNG. ✨

Feito só com **HTML, CSS e JavaScript puro**, sem frameworks e sem instalar nada.

>  **Inspiração:** este projeto foi inspirado no **cute-photobooth** (JiggleDuo Photobooth), criado por **[lovesulei](https://github.com/lovesulei)**.


## Tecnologias

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e identidade visual.
- **JavaScript:** lógica e interatividade da aplicação.

##  Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/kareneduuniesp/TED04.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd TED04/little-memories-photobooth
   ```

3. Abra o arquivo `index.html` no navegador.

4. Caso o projeto utilize a câmera do dispositivo, permita o acesso quando solicitado pelo navegador.

## Organização do projeto

A aplicação está organizada dentro da pasta `little-memories-photobooth`, localizada neste repositório.

## Objetivo acadêmico

Desenvolver uma aplicação web criativa, colocando em prática conhecimentos de HTML, CSS e JavaScript, além de explorar conceitos de interface, interação com o usuário e desenvolvimento front-end.

## Inspiração e créditos

O visual e a ideia do Smilee foram inspirados no **cute-photobooth** (JiggleDuo Photobooth), criado por **lovesulei**:

🔗 **https://github.com/lovesulei/cute-photobooth**

O projeto dela é uma cabine de fotos em React, com molduras ilustradas, adesivos desenhados à mão e uma estética aconchegante em tons de rosa e marrom. De lá vieram a inspiração para:

- a **paleta de cores** (marrom suave `#8c5b4a`, rosa e tons de creme);
- o estilo dos **botões** (fundo branco, borda marrom e cantos arredondados);


O Little Memories **não copia o código** do projeto original: foi escrito do zero, em HTML, CSS e JavaScript puro, e funciona de outra forma, com contagem automática, tira de 4 fotos e download em PNG.
